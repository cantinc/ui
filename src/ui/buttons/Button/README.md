# Button

This component reacts on click.

```typescript
import { Button } from '@cantinc/ui'
```

## Dependencies

- [Flex](/ui/layout/flex)

## ButtonProps

| **Name** | **Description**                                                                    | **Type**      |
|----------|------------------------------------------------------------------------------------|---------------|
| view     | Determines the visual style of the button (e.g., primary, secondary, or negative). | `ButtonViews` |
| width    | Sets the width of the button in pixels.                                            | `number`      |
| disabled | Disables the button, preventing user interaction.                                  | `boolean`     |
